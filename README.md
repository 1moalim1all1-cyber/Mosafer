# مسافر | Mosafer

مشاركة رحلات بين الركاب والسائقين، بواجهة React + TypeScript + Vite، وFirebase Auth/Firestore، ووظائف Firebase للعمليات الحساسة. أندرويد عبر Capacitor.

## دورة طلب الرحلة

1. الراكب ينشر طلبًا بالمكان والموعد وعدد المقاعد.
2. السائق المعتمد يختار **قبول الطلب وتقديم عرض** ويحدد السعر والموعد.
3. الراكب يقبل عرضًا واحدًا أو يرفضه. القبول ينشئ رحلة وحجزًا مؤكدًا للطرفين ويقفل العروض الأخرى تلقائيًا.
4. الحجز يظهر في «حجوزاتي» ولوحة السائق، مع التتبع وكود ركوب خاص بالراكب.
5. الحجز المباشر في رحلة منشورة ينتظر قبول السائق أو رفضه.

## التشغيل والتحقق

```sh
npm ci
npm ci --prefix functions
npm run dev
npm run build
npm run lint
./functions/node_modules/.bin/firebase emulators:exec --only firestore --project demo-mosafer 'npm --prefix functions test'
```

**تشغيل النسخة الجديدة يحتاج نشر وظائف Firebase وترحيل البيانات ونشر القواعد قبل تحديث الموقع أو APK.** اتبع [دليل النشر والترحيل](docs/secure-acceptance-rollout.md). بناء الواجهة وحده لا ينشر الخادم.

الدفع الحالي **كاش فقط**. الإيداع والسحب بمراجعة الإدارة؛ الدفع بالمحفظة والكوبونات ومكافآت الدعوات غير مفعّلة. تسجيل الهاتف الحالي بدون SMS، واستعادة الحساب عبر الدعم. لا تعتبر هذه الخدمات مفعلة قبل استكمال إعدادها واختبارها.

`npm run build:app` يبني واجهة أندرويد. يوجد بناء APK للتجربة وworkflow منفصل لإنشاء إصدار AAB موقّع بعد إعداد أسرار التوقيع.
