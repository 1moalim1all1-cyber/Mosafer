# مسافر | Mosafer

تطبيق ويب لمشاركة الرحلات بين الركاب والسائقين، مع لوحة إدارة، محفظة، شات، وتتبع. الواجهة **React 19 + TypeScript + Vite**، والبيانات على **Firebase Auth و Firestore**. نسخة أندرويد عبر **Capacitor**.

## ما يعمل حاليًا

- تسجيل ودخول برقم الهاتف (معرّف داخلي، بدون SMS)
- بحث وحجز رحلات (كاش أو محفظة + كوبونات)
- لوحة سائق: مستندات، موافقة الإدارة، إنشاء رحلات، إدارة حجوزات وPIN
- محفظة: إيداع/سحب بمراجعة الإدارة، ودفع من الرصيد
- مجتمع طلبات الرحلات والعروض
- شات، إشعارات داخل التطبيق، مفضلة، تتبع موقع السائق
- لوحة إدارة: مستخدمون، رحلات، سائقون، محفظة، محافظات، كوبونات، شكاوى، إعدادات
- ترجمة عربية/إنجليزية ونشر GitHub Pages + بناء APK للتجربة

## التشغيل

```bash
git clone https://github.com/1moalim1all1-cyber/Mosafer.git
cd Mosafer
npm install
# اختياري: انسخ .env.example إلى .env وضع مفاتيح Firebase
npm run dev
```

البناء: `npm run build` للموقع (مسار `/Mosafer/`)، و`npm run build:app` لتطبيق Capacitor.

## ملاحظات تقنية

- لا توجد Cloud Functions؛ العمليات الحساسة تتم من العميل مع قواعد Firestore.
- استعادة كلمة المرور تتم عبر الدعم لأن الحساب مربوط برقم هاتف وليس بريدًا حقيقيًا.
- مكافأة دعوة الأصدقاء غير مفعّلة من السيرفر حتى يتوفر تحقق خلفي آمن.
